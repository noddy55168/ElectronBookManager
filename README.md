# ElectronBookManager
 使用NET10 sqlite Electron的迷你小程式(練習OOP MVVM用)
 
# 如何啟動(.exe或Visual Studio)
 EXE版：請到 "bookmanagerwebapp\bin\release\net10.0\publish" 並執行 "BookManagerWebApp 1.0.0.exe"
 
 Visual Studio版：直接F5執行(https版本)
